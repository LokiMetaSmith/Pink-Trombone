## Archived: 2026-10-31
* Repository Context: This repository is a programmable version of Neil Thapen's Pink Trombone, a bare-handed speech synthesis tool.
* It uses Web Audio API (Audio Worklet Processor) to simulate sound generated in the glottis and filtered by the vocal tract shape.
* The API provides options to manipulate audio parameters like intensity, frequency, tenseness, loudness, vibrato, tongue placement, and vocal tract constrictions.
* Core files include `pink-trombone.min.js` and `pink-trombone-worklet-processor.min.js`, which are used as a custom element `<pink-trombone>`.
